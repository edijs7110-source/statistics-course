Syllabus

Every module, lesson and project in the course

The course has 11 modules and 149 lessons. Module 0 covers the prerequisites. Modules 1 and 2 match the certificate’s two required courses, and Modules 3–10 match its eight electives. The order is chosen so each module only uses ideas from earlier ones.

Lessons are numbered module.lesson, so 2.5 is the fifth lesson of Module 2.

Module 0 · Foundations

Course: prerequisite material
Length: 14 lessons and a project
Study plan: weeks 1–15
Before this: nothing, start here

Everything the certificate assumes you already know: R programming from the first line of code, describing data, probability, statistical inference, and the matrix algebra that regression is built on.

What it covers: Stands in for the prerequisite every course lists: one semester of applied statistics. It adds an introduction to R programming and the linear algebra used from Module 2 onward.

  • 0.1 Welcome to R
    the console, R as a calculator, objects and assignment, functions and arguments, getting help, reading error messages
  • 0.2 Vectors and data types
    creating vectors, sequences, vectorized arithmetic, numeric, character and logical types, comparisons, indexing, missing values, factors
  • 0.3 Data frames
    observations and variables, built-in datasets, inspecting data, selecting rows and columns, summaries by group, reading CSV files
  • 0.4 Programming basics
    if and else, for and while loops, writing your own functions, the apply family, debugging
  • 0.5 Visualizing data with ggplot2
    the grammar of graphics, histograms, boxplots, scatterplots, bar charts, facets, habits of good charts
  • 0.6 Transforming data with dplyr
    filter, select, mutate, arrange, summarise, group_by, the pipe
  • 0.7 Describing data
    center (mean, median), spread (variance, standard deviation, IQR), shape, outliers, z-scores, correlation
  • 0.8 Probability
    sample spaces and events, probability rules, conditional probability, independence, Bayes’ theorem, simulation
  • 0.9 Discrete random variables
    probability mass functions, expected value and variance, Bernoulli, binomial and Poisson distributions, R’s d/p/q/r functions
  • 0.10 Continuous distributions
    densities and integrals, cumulative distribution functions, uniform, exponential and normal distributions, standardizing, Q-Q plots
  • 0.11 Sampling distributions and the CLT
    sampling variability, the law of large numbers, the central limit theorem, standard errors
  • 0.12 Confidence intervals
    estimators, the t distribution, intervals for means and proportions, what 95% confidence means, sample size
  • 0.13 Hypothesis testing
    null and alternative hypotheses, p-values, Type I and II errors, power, one- and two-sample t-tests, paired tests, chi-square tests
  • 0.14 Matrices for statistics
    vectors and matrices in R, matrix multiplication, transpose, inverse, solving linear systems, determinants, a first look at eigenvalues

Project: Exploratory data analysis report. Pick a dataset, ask three questions about it, and answer them with graphs, summaries, a confidence interval and a hypothesis test, written up as a Quarto report in RStudio.

Module 1 · Statistical Data Management

Course: STAT 580
Length: 14 lessons and a project
Study plan: weeks 16–30
Before this: Module 0

How data is organized, stored, cleaned, combined and moved between software, and how to analyze data with missing values.

What it covers: Data organization and structures, designing statistical databases, analysis with statistical software, importing and exporting data between software, and missing data analysis.

  • 1.1 Reproducible data workflows
    RStudio projects, folder structure, file paths, naming conventions, Quarto reports, version control with Git
  • 1.2 Data structures in R
    vectors, lists, matrices, arrays, data frames and tibbles, attributes, choosing the right structure
  • 1.3 Tidy data and reshaping
    tidy data principles, pivot_longer and pivot_wider, separating and uniting columns, wide and long formats
  • 1.4 Advanced data transformation
    across(), case_when(), window functions, ranks, cumulative and lagged values, grouped operations
  • 1.5 Combining datasets
    keys, inner, left and full joins, semi and anti joins, binding rows and columns, join pitfalls
  • 1.6 Designing statistical databases
    the relational model, entity-relationship diagrams, primary and foreign keys, normalization, data dictionaries
  • 1.7 SQL fundamentals
    databases from R with DBI and SQLite, SELECT, WHERE, ORDER BY, GROUP BY, HAVING, aggregate functions
  • 1.8 SQL beyond the basics
    joins in SQL, subqueries, common table expressions, window functions, creating tables and indexes, dbplyr
  • 1.9 Importing and exporting data
    CSV, Excel, JSON and fixed-width files, SAS, SPSS and Stata files with haven, labelled data, encodings, Parquet
  • 1.10 Text, dates and categories
    strings and regular expressions with stringr, dates and times with lubridate, factors with forcats
  • 1.11 Data quality and validation
    finding errors and duplicates, validation rules, outlier checks, documenting cleaning decisions
  • 1.12 Missing data I: patterns and mechanisms
    MCAR, MAR and MNAR, visualizing missingness, what deleting incomplete cases does, single imputation and its problems
  • 1.13 Missing data II: multiple imputation
    multiple imputation with mice, Rubin’s rules, imputation diagnostics, sensitivity analysis
  • 1.14 Working across statistical software
    reading SAS, SPSS and Stata code, R equivalents of common procedures, moving data and results between tools

Project: Build an analysis-ready database. Take messy data spread over several files and formats, design a database for it, clean and validate it, handle the missing values, load it into SQLite and document it in a codebook.

Module 2 · Regression and ANOVA

Course: STAT 665 / STAT 562
Length: 15 lessons and a project
Study plan: weeks 31–46
Before this: Modules 0 and 1

Modeling how a response depends on predictors: simple and multiple regression, checking and repairing models, ANOVA for designed experiments, and logistic regression for yes/no outcomes.

What it covers: Correlation; simple and multiple linear regression with least squares and matrix notation; model building and checking; estimation and hypothesis tests; outliers, influence, multicollinearity and transformations; categorical regressors; logistic regression; and (from STAT 562) multifactor analysis of variance.

  • 2.1 Correlation
    scatterplots, Pearson and Spearman correlation, inference for a correlation, correlation and causation, regression to the mean
  • 2.2 Simple linear regression
    the linear model, least squares derived with calculus, interpreting slope and intercept, residuals, R-squared
  • 2.3 Inference in simple regression
    sampling distributions of the estimates, t-tests and confidence intervals, the ANOVA F-test, confidence and prediction intervals
  • 2.4 Regression in matrix notation
    the design matrix, normal equations, the least squares solution in matrix form, the hat matrix, variance of the estimates
  • 2.5 Multiple linear regression
    partial effects, interpreting coefficients, adjusted R-squared, added-variable plots, confounding
  • 2.6 Hypothesis tests in multiple regression
    overall and partial F-tests, nested models, general linear hypotheses, sequential and partial sums of squares
  • 2.7 Categorical regressors and interactions
    dummy variables, contrasts, interactions, centering
  • 2.8 Checking model assumptions
    residual plots, checking linearity, constant variance, normality and independence, formal tests
  • 2.9 Transformations
    log and power transformations, Box-Cox, polynomial terms, weighted least squares
  • 2.10 Outliers and influence
    leverage, studentized residuals, Cook’s distance, DFFITS and DFBETAS, what to do about unusual points
  • 2.11 Multicollinearity
    correlated predictors, variance inflation factors, condition numbers, remedies
  • 2.12 Model building and selection
    modeling strategies, AIC, BIC and Mallows’ Cp, stepwise and best-subset selection, cross-validation, overfitting
  • 2.13 One-way ANOVA
    ANOVA as regression, the F-test, multiple comparisons with Tukey and Bonferroni, contrasts, assumptions
  • 2.14 Multifactor ANOVA
    two-way factorial designs, interaction plots, blocking, unbalanced designs, ANCOVA
  • 2.15 Logistic regression
    odds and log-odds, maximum likelihood, odds ratios, deviance tests, predicted probabilities and classification

Project: A complete regression analysis. Build, check and interpret a regression model that answers a real question, then write it up as a report someone else could act on.

Module 3 · Multivariate Statistical Methods

Course: STAT 668
Length: 13 lessons and a project
Study plan: weeks 47–60
Before this: Modules 0 and 2

Analyzing several response variables at once: statistical distance, the multivariate normal distribution, Hotelling’s T², MANOVA, repeated-measures and nested designs, canonical correlation and discriminant analysis.

What it covers: Distance concepts; Hotelling’s T²; multivariate ANOVA; multivariate regression and correlation; linear contrasts; factorial, nested and repeated-measures designs; Bonferroni and chi-square tests; linear discriminant analysis; canonical correlation; applications.

  • 3.1 Multivariate data and matrix algebra
    data matrices, mean vectors, covariance and correlation matrices, linear combinations, eigenvalues and eigenvectors
  • 3.2 Statistical distance
    Euclidean and Mahalanobis distance, standardization, ellipses of constant distance
  • 3.3 The multivariate normal distribution
    the density and its properties, marginal and conditional distributions, checking multivariate normality
  • 3.4 Inference for a mean vector
    Hotelling’s T², confidence regions, simultaneous intervals, Bonferroni intervals, large-sample chi-square tests
  • 3.5 Comparing two mean vectors
    paired comparisons, the two-sample T² test, unequal covariance matrices, profile plots
  • 3.6 One-way MANOVA
    Wilks’ lambda, Pillai’s trace and related statistics, assumptions, Box’s M test
  • 3.7 Linear contrasts and simultaneous inference
    contrast matrices, simultaneous confidence intervals, follow-up comparisons after MANOVA
  • 3.8 Factorial MANOVA
    two-way multivariate designs, interaction effects, univariate follow-up tests
  • 3.9 Repeated-measures designs
    profile analysis, repeated-measures ANOVA and the multivariate approach, sphericity
  • 3.10 Nested designs
    nested factors, hierarchical data, nested MANOVA, a first look at mixed models
  • 3.11 Multivariate regression and correlation
    multivariate multiple regression, partial and multiple correlation, inference
  • 3.12 Canonical correlation analysis
    canonical variates, significance tests, interpretation
  • 3.13 Linear discriminant analysis
    Fisher’s discriminant function, classification rules, error rates, quadratic discriminant analysis

Project: A multivariate study. Analyze a dataset with several outcomes: test group differences with MANOVA, follow up with contrasts, and build a discriminant rule that classifies new cases.

Module 4 · Advanced Statistical Computing

Course: STAT 583
Length: 14 lessons and a project
Study plan: weeks 61–75
Before this: Modules 0, 1 and 2

The algorithms behind modern statistics: random number generation, simulation, resampling, numerical optimization, the EM algorithm, MCMC, smoothing, and clustering and classification.

What it covers: Data management, random number generation, resampling methods, numerical optimization, Markov chain Monte Carlo, smoothing methods, and data mining with clustering and classification.

  • 4.1 Efficient and reliable R
    vectorization, profiling and benchmarking, memory, functional programming, managing large data
  • 4.2 Numbers inside the computer
    floating-point arithmetic, rounding error, numerically stable algorithms
  • 4.3 Random number generation
    pseudo-random generators, seeds, testing randomness, the inverse-transform method
  • 4.4 Simulating from distributions
    rejection sampling, transformation methods, mixtures, designing simulation studies
  • 4.5 Monte Carlo integration
    Monte Carlo estimates and their error, importance sampling, antithetic and control variates
  • 4.6 The bootstrap
    nonparametric and parametric bootstrap, bootstrap confidence intervals, bootstrapping regression
  • 4.7 Permutation tests, the jackknife and cross-validation
    permutation tests, jackknife estimates of bias and variance, cross-validation
  • 4.8 Root finding and one-dimensional optimization
    bisection, Newton-Raphson, golden-section search, convergence
  • 4.9 Multivariate optimization and maximum likelihood
    gradient descent, Newton’s method, quasi-Newton methods, Nelder-Mead, optim(), Fisher scoring
  • 4.10 The EM algorithm
    missing data and latent variables, mixture models, convergence
  • 4.11 Markov chain Monte Carlo
    Markov chains, the Metropolis-Hastings algorithm, tuning, convergence diagnostics
  • 4.12 Gibbs sampling
    full conditional distributions, data augmentation, blocking
  • 4.13 Smoothing methods
    kernel density estimation, kernel regression, loess, smoothing splines, choosing the bandwidth
  • 4.14 Data mining: clustering and classification
    k-means, hierarchical clustering, k-nearest neighbors, classification trees, judging the results

Project: A simulation study. Design and run a simulation study that compares statistical methods, implementing at least one of them (the bootstrap, EM or MCMC) from scratch.

Module 5 · Bayesian Statistics

Course: STAT 576
Length: 13 lessons and a project
Study plan: weeks 76–89
Before this: Modules 0, 2 and 4

Treating unknown quantities as probability distributions: priors and posteriors, conjugate models, sampling methods, MCMC, hierarchical models and Bayesian model checking.

What it covers: Basic concepts of Bayesian theory, sampling methods, Markov chain Monte Carlo and hierarchical modeling, applied to problems in the natural and physical sciences and engineering.

  • 5.1 Bayesian thinking
    probability as uncertainty, prior, likelihood and posterior, grid approximation
  • 5.2 The beta-binomial model
    conjugate priors, the posterior as a compromise, credible intervals
  • 5.3 Choosing priors
    informative, weakly informative and noninformative priors, Jeffreys priors, prior predictive checks, sensitivity analysis
  • 5.4 More conjugate models
    gamma-Poisson and normal-normal models, the posterior predictive distribution
  • 5.5 Posterior inference
    point estimates, credible and HPD intervals, Bayesian hypothesis tests, Bayes factors
  • 5.6 Multiparameter models
    the normal model with unknown mean and variance, marginal posteriors, Monte Carlo summaries
  • 5.7 Sampling from posteriors
    direct simulation, rejection sampling, importance sampling
  • 5.8 MCMC in practice
    Metropolis and Gibbs revisited, Hamiltonian Monte Carlo, trace plots, R-hat and effective sample size
  • 5.9 Probabilistic programming with Stan
    writing models in Stan, fitting them from R with brms, reading the output
  • 5.10 Bayesian linear regression
    priors on coefficients, posterior predictive checks, comparison with least squares
  • 5.11 Hierarchical models I
    partial pooling, exchangeability, the eight-schools model
  • 5.12 Hierarchical models II
    hierarchical regression, varying intercepts and slopes, hierarchical logistic and Poisson models
  • 5.13 Model checking and comparison
    posterior predictive checks, WAIC and leave-one-out cross-validation, the Bayesian workflow, scientific applications

Project: A Bayesian hierarchical analysis. Fit, check and compare hierarchical models for grouped data from science or engineering, and explain what partial pooling changed.

Module 6 · Time Series Analysis

Course: STAT 577
Length: 13 lessons and a project
Study plan: weeks 90–103
Before this: Modules 0 and 2

Data collected over time: stationarity, ARIMA and seasonal models, forecasting, regression with autocorrelated errors, multivariate series, cointegration, volatility and long memory.

What it covers: Stationarity; ARIMA modeling with seasonality; parameter estimation, diagnostics and forecasting; regression with autocorrelated errors; cointegration and multivariate ARMA models; heteroscedasticity and long-memory models.

  • 6.1 Time series data
    time series objects, time plots, seasonal and lag plots, trend, seasonality and cycles
  • 6.2 Decomposition and smoothing
    moving averages, classical and STL decomposition, exponential smoothing
  • 6.3 Stationarity and autocorrelation
    white noise, random walks, the ACF and PACF, differencing, unit-root tests
  • 6.4 Autoregressive models
    AR(p) processes, stationarity conditions, Yule-Walker estimation
  • 6.5 Moving-average and ARMA models
    MA(q) processes, invertibility, ARMA(p, q), identifying models from the ACF and PACF
  • 6.6 ARIMA modeling
    the Box-Jenkins approach, maximum likelihood estimation, choosing models with AIC
  • 6.7 Model diagnostics
    residual analysis, the Ljung-Box test, overfitting checks
  • 6.8 Forecasting
    point forecasts and prediction intervals, accuracy measures, time-series cross-validation, benchmark methods
  • 6.9 Seasonal ARIMA
    seasonal differencing, SARIMA models, identification and fitting
  • 6.10 Regression with autocorrelated errors
    dynamic regression, ARIMA errors, generalized least squares, spurious regression
  • 6.11 Multivariate time series
    vector autoregression, Granger causality, impulse responses, VARMA models
  • 6.12 Cointegration
    common stochastic trends, the Engle-Granger and Johansen methods, error-correction models
  • 6.13 Volatility and long memory
    ARCH and GARCH models, long-memory processes, ARFIMA

Project: A forecasting study. Model and forecast a realistic seasonal series, compare several methods with time-series cross-validation, and report forecasts with honest uncertainty.

Module 7 · Introduction to Machine Learning

Course: STAT 584
Length: 14 lessons and a project
Study plan: weeks 104–118
Before this: Modules 0, 2 and 3

Statistical learning for prediction and pattern-finding: resampling, classification, regularization, nonlinear models, support vector machines, neural networks, principal components and clustering.

What it covers: Methods of statistical learning, including generalized (multinomial) logistic regression, ridge regression, neural networks, support vector machines, principal components analysis, and k-means and hierarchical clustering.

  • 7.1 What is statistical learning?
    prediction and inference, supervised and unsupervised learning, the bias-variance trade-off
  • 7.2 Resampling and model assessment
    training and test sets, k-fold cross-validation, the bootstrap, data leakage
  • 7.3 k-nearest neighbors
    kNN for regression and classification, choosing k, the curse of dimensionality
  • 7.4 Logistic and multinomial regression
    multiple logistic regression, multinomial (generalized) logistic regression, decision boundaries
  • 7.5 Discriminant analysis and naive Bayes
    LDA, QDA and naive Bayes as generative classifiers, when each works best
  • 7.6 Evaluating classifiers
    confusion matrices, sensitivity and specificity, ROC curves and AUC, precision and recall, class imbalance
  • 7.7 Ridge regression
    shrinkage, the bias-variance trade-off, choosing lambda by cross-validation, standardizing predictors
  • 7.8 Lasso and elastic net
    sparsity and variable selection, glmnet, regularized logistic regression
  • 7.9 Beyond linearity
    polynomial regression, step functions, splines, generalized additive models
  • 7.10 Support vector machines
    maximal-margin classifiers, soft margins, kernels, multiclass SVMs
  • 7.11 Neural networks
    perceptrons, multilayer networks, backpropagation, gradient descent, regularization
  • 7.12 Principal components analysis
    directions of maximum variance, scree plots, biplots, principal components regression
  • 7.13 Clustering
    k-means, hierarchical clustering and linkage, choosing the number of clusters
  • 7.14 The machine-learning workflow
    tidymodels recipes and workflows, hyperparameter tuning, final models, interpretability and fairness

Project: A prediction challenge. Build, tune and compare several models on a realistic prediction problem, and explain which one you would deploy and why.

Module 8 · Applied Analytics: Decision Trees

Course: STAT 585
Length: 13 lessons and a project
Study plan: weeks 119–132
Before this: Modules 0, 2 and 7

Predictive modeling for business problems with CHAID, CART, logistic regression and neural networks, plus the tree ensembles that grew out of them.

What it covers: Selected topics in predictive modeling using CHAID, classification and regression trees (CART), logistic regression and neural networks.

  • 8.1 Predictive modeling in practice
    the analytics workflow, business objectives, target variables, training, validation and test partitions
  • 8.2 How decision trees work
    recursive partitioning, impurity measures (Gini and entropy), stopping rules, reading a tree
  • 8.3 CART classification trees
    growing trees with rpart, class probabilities, priors and misclassification costs
  • 8.4 CART regression trees
    variance-reduction splits, piecewise-constant predictions, comparison with linear regression
  • 8.5 Pruning and tree size
    cost-complexity pruning, cross-validation, the one-standard-error rule
  • 8.6 CHAID
    chi-square splitting, merging categories, Bonferroni adjustments, multiway splits
  • 8.7 Conditional inference trees and C5.0
    unbiased variable selection, ctree, C5.0, comparing tree algorithms
  • 8.8 Missing values and categorical inputs
    surrogate splits, high-cardinality categories, preparing data for trees
  • 8.9 Logistic regression for prediction
    selecting and transforming inputs, scoring new data, comparison with trees
  • 8.10 Neural networks for prediction
    multilayer perceptrons, training and early stopping, interpretation
  • 8.11 Assessing and comparing models
    lift and gains charts, ROC curves, profit and cost matrices, choosing a cutoff
  • 8.12 Bagging and random forests
    bootstrap aggregation, random forests, out-of-bag error, variable importance
  • 8.13 Boosting
    gradient boosting, XGBoost, tuning, partial dependence and SHAP explanations

Project: A business analytics case study. Predict customer churn or credit risk with CHAID, CART, logistic regression, a neural network and an ensemble, then recommend one using profit-based assessment.

Module 9 · Spatial-temporal Statistics

Course: STAT 586
Length: 13 lessons and a project
Study plan: weeks 133–146
Before this: Modules 0, 2 and 6

Data tied to places and times: geostatistics and kriging, models for areal data, point patterns, and models for large spatio-temporal datasets.

What it covers: Basic concepts of geostatistics, point patterns and areal units; spatio-temporal modeling of high-dimensional data; applications in the natural and physical sciences and engineering.

  • 9.1 Spatial data and maps
    geostatistical, areal and point-pattern data, coordinate reference systems, sf objects, making maps
  • 9.2 Spatial dependence
    spatial autocorrelation, Moran’s I and Geary’s C, local indicators of spatial association
  • 9.3 Variograms
    stationarity and isotropy, empirical variograms, spherical, exponential and Matérn models
  • 9.4 Kriging
    simple and ordinary kriging, kriging variance, cross-validation with gstat
  • 9.5 Beyond ordinary kriging
    universal and regression kriging, anisotropy, the Gaussian-process view
  • 9.6 Areal data and spatial weights
    neighborhoods, spatial weight matrices, choropleth maps, testing for autocorrelation
  • 9.7 Models for areal data
    SAR and CAR models, spatial regression, disease mapping
  • 9.8 Point patterns I
    intensity, complete spatial randomness, quadrat tests, kernel estimates of intensity
  • 9.9 Point patterns II
    Ripley’s K and L functions, clustering and inhibition, Poisson and Cox process models
  • 9.10 Spatio-temporal data
    data structures, Hovmöller plots and animations, exploratory analysis
  • 9.11 Spatio-temporal covariance and kriging
    separable and non-separable covariances, spatio-temporal variograms, prediction
  • 9.12 High-dimensional spatio-temporal data
    empirical orthogonal functions, basis functions, dimension reduction
  • 9.13 Dynamic spatio-temporal models
    hierarchical and state-space models, environmental applications

Project: An environmental spatio-temporal analysis. Map, model and predict an environmental variable such as air pollution or temperature across space and time, including maps of the uncertainty.

Module 10 · Introduction to Bioinformatics

Course: CPSC 545
Length: 13 lessons and a project
Study plan: weeks 147–160
Before this: Modules 0, 1 and 4

Statistics and algorithms for biological data: molecular genetics, biological databases, sequence alignment and database search, phylogenetic trees, structure prediction and microarray analysis.

What it covers: Concepts of molecular genetics, biological databases, database searching, sequence alignment, phylogenetic trees, structure prediction and microarray data analysis.

  • 10.1 Molecular genetics for data scientists
    DNA, RNA and proteins, genes and the genetic code, mutation, the central dogma
  • 10.2 Biological databases and file formats
    GenBank, UniProt, PDB and Ensembl, FASTA, FASTQ and GenBank files, Bioconductor
  • 10.3 Working with sequences in R
    Biostrings, reverse complements, translation, GC content, motifs and k-mers
  • 10.4 Pairwise alignment I: global alignment
    dot plots, dynamic programming, the Needleman-Wunsch algorithm
  • 10.5 Pairwise alignment II: local alignment and scoring
    Smith-Waterman, gap penalties, PAM and BLOSUM matrices, statistical significance of scores
  • 10.6 Database searching
    BLAST and FASTA heuristics, E-values, interpreting search results
  • 10.7 Multiple sequence alignment
    progressive alignment, profiles, conserved regions
  • 10.8 Phylogenetic trees I
    tree terminology, distance methods, UPGMA and neighbor joining
  • 10.9 Phylogenetic trees II
    parsimony, maximum likelihood, bootstrap support
  • 10.10 Hidden Markov models for sequences
    CpG islands and gene finding, the Viterbi and forward algorithms
  • 10.11 Protein structure prediction
    levels of protein structure, secondary-structure prediction, homology modeling, AlphaFold
  • 10.12 Microarray data analysis I
    how microarrays work, preprocessing, normalization, quality control
  • 10.13 Microarray data analysis II
    differential expression with limma, multiple testing and false discovery rates, clustering and heatmaps

Project: From sequences to expression. Identify ten new bacterial isolates with a 16S tree and its bootstrap support, check whether their ketoreductase genes are intact, and find the genes that respond to high substrate load in a microarray experiment, then recommend a production strain.
