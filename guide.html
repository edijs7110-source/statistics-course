How to use this course

What’s in a lesson, how the live R boxes work, and how to study on your phone

Finding your way around

  • Lessons go one step at a time. Use Continue and Back at the bottom, or the Step 2 of 9 button at the top to jump to any step. If you’d rather scroll through everything, that menu also has Show the whole lesson on one page.
  • The Course button (top right) opens your current module: its lessons, your progress, the study plan and the full syllabus. Everything else stays out of the way until you need it.
  • Fizz is the little flask who pops up with tips. When Fizz says something, it’s usually worth reading.

The big picture

The course has 11 modules. Module 0 builds the foundations: R programming, describing data, probability and statistical inference. Modules 1–10 each cover one graduate course. Study them in order, one lesson a week; the study plan turns that into dates. Each module page says which earlier modules it builds on.

What’s in a lesson

Every lesson has the same parts, so you always know where you are.

What you’ll learn
The goals of the lesson. Come back to them at the end and check you can do each one.
Examples
Code with its result shown underneath. Lines starting with #> are what R printed.
Live R boxes
Code boxes with a Run Code button. They run real R in your browser. Change the code and run it again as often as you like. Start Over restores the original code.
Go deeper boxes
Collapsed boxes with the math behind an idea, such as a derivation or a proof. They’re optional the first time through, but worth coming back to.
Exercises
Live boxes that check your answer when you run them. Each has hints, revealed one at a time, and a full solution. Try for a few minutes before you open a hint, and don’t open the solution until you’ve either solved it or genuinely tried.
Quiz
Short multiple-choice questions. Click an answer to see whether it’s right and why.
Practice in RStudio
A small task in RStudio on your own computer, because that’s where real work happens. If you’re only using a phone or tablet, skip these and come back to them later.
Read more
Chapters from free textbooks that cover the same material in a different voice. Optional, but a second explanation often makes things click.

At the bottom of every lesson there’s a Mark lesson complete button. Completed lessons get a ✓ in the menu, and your progress shows on the home page and module pages.

Live R boxes

  • The first time you press Run Code on a page, your browser downloads R. That takes a few seconds, sometimes longer on a slow connection; after that, code runs instantly.
  • Boxes on the same page share their objects, like one R session. If a box uses an object made earlier on the page, run the earlier box first.
  • Exercises run in their own space, so an exercise can’t break the rest of the page.
  • Your edits are saved in this browser, so you can close the page and come back. Start Over brings back the original code.
  • The boxes need an internet connection to load R. If a box doesn’t respond, reload the page.

Studying on your phone

The course works on a phone like an app:

  • iPhone (Safari): tap the Share button, then Add to Home Screen.
  • Android (Chrome): tap the ⋮ menu, then Add to Home screen or Install app.

Reading, quizzes and small code changes work well on a phone. For exercises with a lot of typing, a laptop or tablet with a keyboard is much more comfortable.

Your progress is private

Progress, quiz answers and your code edits are saved only in the browser you’re using. Nothing is sent anywhere, and nobody else can see it. That also means each device and browser keeps its own progress, and clearing your browser’s data for this site resets it.

R and RStudio on your own computer

The live boxes are enough for the lessons, but projects and the Practice in RStudio tasks need R and RStudio installed. Both are free.

  1. Install R from CRAN, the official R site. Pick your operating system and download the latest version.
  2. Install RStudio Desktop from Posit. It’s the program you’ll write R in; it uses the R you installed in step 1.
  3. Open RStudio, go to Tools → Global Options → General, untick Restore .RData into workspace at startup, and set Save workspace to .RData on exit to Never. That way every session starts clean, and your scripts are the record of your work.
  4. Install the packages the course uses by running this in the RStudio console:
install.packages("tidyverse")

Later modules list any extra packages they need.

Where the data come from

Almost all of the course’s datasets are simulated: written by a script to behave like real plant, lab or business data, with problems planted on purpose. The plant, its people and their numbers are made up. That’s what lets the lessons say what the right answer is, and let you check it against the truth.

A few are real measurements, such as R’s built-in stackloss (a nitric acid plant), Puromycin (enzyme kinetics), pressure (mercury vapor pressure) and AirPassengers, and the historical Nile minima in Module 6.

So treat the numbers as practice, never as facts about real chemicals, plants or suppliers. And expect real data to be harder: nobody plants its problems for you to find, nobody knows the true answer, and the question often isn’t clear until you’ve talked to the person asking. The best next step after any module is to try its methods on data of your own.

Tips for learning statistics

  • Predict before you run. Guess what the code will print, then run it. Being wrong is how you learn.
  • Type, don’t copy. Your fingers learn the syntax faster than your eyes do.
  • Explain it out loud. If you can explain an idea to a friend in plain words, you understand it. If you can’t, reread that section.
  • Errors are normal. Read the message: it usually tells you what’s wrong. Lesson 0.1 shows you how.
  • Review a little, often. Ten minutes redoing old exercises each week beats a long cram before moving on.
